The signature

The island is the desktop's voice

One pill at the top of the screen tells you what just happened and what's going on. It grows only as much as the moment needs, then settles back into a clock.

  • At restTime and date, with a live equalizer when music plays.
  • Now playingHover to expand: artwork, controls and a glow in the album's own colour.
  • ArrivalsNotifications, volume, brightness, Caps Lock, keyboard layout, Wi-Fi and devices.
  • Live workTimers and stopwatches, screen recording, download progress, updates.
  • GesturesScroll for volume (Shift: brightness), middle-click to play or pause, right-click for background apps.

Calm by default

Quiet when you need it, secure when it matters

Focus modes, per-app volume, a lock screen with Face ID, and admin prompts drawn by the desktop itself.

Lock screen

Widgets for music, battery, calendar and notification counts, never their content. Face ID unlocks the lock screen only; your password always works.

Focus modes

Work lets the apps you allow through. Game turns effects off. Sleep warms the screen. Put Work and Sleep on a schedule.

Per-app volume

One slider per app that's playing. Click an app's icon to mute just that app.

Admin prompts

Lumen is the polkit agent: a clear card that says what's asking and why. Only the password field takes your keyboard.

Get it

A guided install that asks before every step

Preview everything with a dry run first. Packages come from your distribution. Fonts and the cursor are optional downloads from their official projects. Nothing is ever piped into a shell.

Install

# get the source, then preview, then install
git clone <your Lumen repository> ~/Projects/lumen
cd ~/Projects/lumen
./install.sh --dry-run
./install.sh
Fedora 43+ Arch · EndeavourOS · CachyOS Debian · Ubuntu · Mint openSUSE Tumbleweed

Needs Hyprland 0.56 or newer. The installer checks, and tells you exactly what's missing on your distribution.

What it won't do

  • Touch another Hyprland setup, KDE or your system configuration.
  • Run anything as root except your package manager (and, if you ask, one login-screen entry).
  • Enable Face ID for sudo, logins or admin prompts. It only unlocks the lock screen.
  • Send anything anywhere unless you set it up (weather city, AI provider).

./uninstall.sh undoes it and leaves your packages alone.
